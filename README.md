# 🔹 Task 1: Term Deposit Subscription Prediction

## Objective
Predict whether a bank customer will subscribe to a term deposit based on marketing campaign data.

## Dataset
Bank Marketing Dataset (UCI Machine Learning Repository)

## Approach
- Data cleaning and preprocessing
- Encoding categorical variables
- Model training:
  - Logistic Regression
  - Random Forest
- Model evaluation:
  - Confusion Matrix
  - F1 Score
  - ROC Curve
- Explainability:
  - SHAP used to interpret model predictions

## Key Outcome
- Identified important features influencing customer decisions
- Built interpretable classification models

# 🔹 Task 2: Customer Segmentation

## Objective
Segment customers based on spending behavior to support targeted marketing strategies.

## Dataset
Mall Customers Dataset

## Approach

- Data preprocessing and scaling
- K-Means clustering
- Optimal cluster selection using Elbow Method

## Key Outcome

- Proposed marketing strategies for each segment

# 🔹 Task 3: Energy Consumption Forecasting

## Objective
Forecast short-term household energy consumption using time series data.

## Dataset
Household Power Consumption Dataset (UCI)

## Approach
- Datetime parsing and resampling
- Feature engineering:
  - Hour
  - Day of week
  - Month
  - Weekend indicator
- Models used:
  - ARIMA
  - Prophet
  - XGBoost
- Evaluation metrics:
  - MAE
  - RMSE

## Key Outcome
- Compared classical and machine learning approaches
- Identified best-performing model for forecasting
